# Isla Juega y Aprende

Web de 96 juegos educativos para niños de 6 y 7 años: matemáticas, lectura, memoria y lógica, y conocimiento del mundo. Cada juego tiene 3 niveles, voz que lee las preguntas y ayudas sin castigo.

- Sin instalación ni dependencias: HTML, CSS y JavaScript con dibujos en SVG.
- Los progresos (estrellas, nombre y avatar) se guardan solo en el navegador.
- Para probarla en local: `python3 -m http.server 8000` y abrir http://localhost:8000
- Cómo se escribe un juego nuevo: ver [SPEC.md](SPEC.md).
